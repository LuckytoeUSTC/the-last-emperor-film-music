# 王伟华教师评审画像

这是一套依据课程原材料整理的模拟评审参考，可用于不同电影的课堂展示，不代表教师本人意见。

## 怎样开始

1. 在GitHub点击 **Code → Download ZIP**，完整解压。保留项目目录结构，不要只取走画像文件夹；原讲义、文字稿和评分原件都在同一项目中，不需要另下附件。
2. 在项目根目录新建“我的展示材料”，放入自己的PPT、讲稿和媒体；媒体已嵌入PPT时直接说明。
3. 新开独立评审对话，选择解压后的项目为工作目录，发送下面的请求。案例和配置由评审助手整理，你只需填写片名和材料位置。

> 请先读“王伟华教师评审画像/AGENTS.md”，再按《课程知识关系》阅读原讲义、文字稿和评分依据。我要评审《填写片名》，PPT、讲稿和媒体位于“填写材料位置”；媒体如已嵌入PPT，请从中读取。请为这部电影建立自己的案例，补充相关专业乐评、研究、制作及奖项资料。然后扮演熟悉本课程知识、影片和评论的老师，按现场主要听讲的顺序，逐页评审PPT、口播和媒体，给出评价、想追问展示者的问题及详细修改意见。先独立记录听讲感受，再查备课依据。只评审，不修改展示；无法实际听看的内容请明确说明。

评审项目已有展示时，给出现有材料路径；材料位置可以填写“展示/成品”。换电影时说明新片名和位置，评审助手会另建案例；不把上一部电影的评论和结论带入新案例。

## 文件与依据

- [AGENTS.md](AGENTS.md)：角色、原材料阅读顺序、逐页听讲方法及报告要求。
- [教师认知与证据](教师认知与证据.md)：正式标准、合理推断与证据边界。
- [课程知识关系](课程知识关系.md)：概念关系与原PDF、文字稿、页码定位。
- [课程原材料索引](../课程资料/资料索引.md)：讲义来源、26秋部分slides和评分原件的入口。
- [新电影模板](../评审案例/新电影模板/README.md)：供评审助手复制和填写的空白案例。
- [评审配置](评审配置.json)：选择当前案例；路径从整个项目根目录计算。

公开项目和私有项目共用这套文件结构、评审流程和启动提示。画像文件夹保持精简，大文件放在外部“课程资料”“整理资料”，具体影片资料放在“参考资料”或相应案例中。更换课程、教师或评分标准时，需要复核正式依据。
