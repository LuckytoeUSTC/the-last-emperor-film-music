# 王伟华教师评审画像

这是一套依据电影音乐艺术课程要求整理的模拟评审参考，可用于不同电影的课堂展示；不代表教师本人，也不预先保证成绩。

## 怎样使用

1. 下载并完整解压本仓库。保留“王伟华教师评审画像”“课程资料”“评审案例”三个同级文件夹。
2. 在根目录新建“我的展示材料”，放入自己的PPT、讲稿和音视频。媒体已嵌入PPT时直接说明。
3. 新开一次独立评审对话，把解压后的项目作为工作目录，发送下面这段话。填写片名与材料位置即可，案例文件和配置由评审助手整理。

> 请先读“王伟华教师评审画像/AGENTS.md”。我要评审《填写片名》，PPT、讲稿和媒体放在“我的展示材料”；媒体如已嵌入PPT，请从中读取。请建立这部电影自己的评审案例，补充相关专业乐评、研究、制作及奖项资料。然后扮演熟悉本课程知识、影片和评论的老师，按现场主要听讲的顺序，逐页评审PPT、口播和媒体，给出评价、想追问展示者的问题及详细修改意见。先独立记录听讲感受，再查备课依据。只评审，不修改展示；无法直接听看的内容请明确说明。

换电影时放入新材料，说明新片名与位置即可。课程知识和规则共用，影片评论和逐页记录另建案例，不能沿用上一部电影的结论。

## 文件说明

- [AGENTS.md](AGENTS.md)：角色要求、逐页听讲方法及报告内容。
- [教师认知与证据](教师认知与证据.md)：正式标准、合理推断及其边界。
- [课程知识关系](课程知识关系.md)：分析概念怎样连接，评审时检验什么。
- [课程知识整理](../课程资料/课程知识整理.md)与[评分要求](../课程资料/展示要求与评分.md)：评审的共用依据。
- [新电影模板](../评审案例/新电影模板/README.md)：空白案例记录，可由评审助手复制、填写。
- [评审配置](评审配置.json)：记录当前案例，初始为空；通常不必手动编辑。

公开版不附原讲义全文。有原课件、当期通知或课堂要求时可补入“课程资料”，据此复核规则；其它老师或课程应先调整画像和评分标准。
