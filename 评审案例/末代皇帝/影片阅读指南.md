# 《末代皇帝》影片与评论阅读指南

这是评审者在听展示之前建立影片知识的入口。资料只用于本片；更换电影时建立新的影片资料包。

## 阅读顺序

1. **人物与影片表达。**结合影片实际场面阅读R02（David Thomson的影评），了解叙事视角、人物处境及影片对历史的处理。记录所观看版本和场面范围。
2. **专业乐评与音乐深析。**先读R06（Broxton）全文，再读S03的动机与谱例分析、S02中本片的相关章节（论文第32—39页，核对PDF页码）。R14提供唱片评论，R10、R11提供具体音乐材料的分析；这些网址中的原文需实际打开。S01补充中西音乐文化的研究视角。
3. **创作与制作。**沿P01、P07、P08等访谈核对创作选择与制作条件，分清访谈涉及的作品和版本；R08、R09、R12等评论用于扩展和比较。
4. **行业与传播。**A01、A02核对奖项，B01核对票房口径。此类事实与对音乐艺术效果的分析分别记录。

## 如何形成评审者的影片知识

在案例的评审输出目录保存“影片知识准备记录.md”，每条观点写清来源ID、作者判断、所据声音或画面、原文位置，以及自己的核对结果。对评论中的不同观点并列记录其证据与评价对象，保留可以向展示者追问的具体问题。

先完成这份记录，再按页接收PPT、口播与媒体。评审报告引用评论或研究时给出来源ID及原文位置；展示者的备课批注在第二轮核对。
