# 《末代皇帝》评审案例

本案例把[展示材料](../../展示/成品)、[影片专属资料](../../影片资料/末代皇帝/README.md)和评审读取顺序连接起来，供评审本次展示或参照建立新案例。

1. 先按[影片阅读指南](影片阅读指南.md)阅读独立评论、深度分析与制作资料，形成影片知识准备记录。
2. 再按[案例配置](案例配置.json)及[逐页材料](逐页材料.json)评审PPT、口播与内嵌媒体。
3. 引用所用观点时，沿[资料来源](资料来源.json)返回原文与具体位置。

需要评审本片时，在请求中明确说明《末代皇帝》与本案例路径；评审其它电影时使用“新电影模板”另建案例。

## 评审输出示例

[《末代皇帝》v10展示评审](评审输出/《末代皇帝》v10展示评审.md)展示了AI教师画像生成的反馈形式：具体页码的评价、修改建议和讲演后追问。它是模拟评审，不是任课教师本人意见；依据口播、静态页面、媒体抽帧及相关资料，未直接聆听声轨或观察现场讲演。

示例供了解输出形式。开展新的独立评审时，在形成自己的逐页记录后再阅读，避免预先沿用已有结论。
