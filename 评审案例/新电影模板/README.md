# 这个空白模板怎样使用

**通常不用你操作这个文件夹。**告诉评审助手要评审的电影，以及PPT、讲稿和媒体在哪里，它会复制模板、建立新案例、填写配置。[使用步骤](../../王伟华教师评审画像/README.md)在画像文件夹的README中。

这个模板只是一套空白记录表，供每部电影分别记录材料，避免把上一部电影的评论和结论用错地方。

## 如果你想自己先整理文件

下面以《爱乐之城》为例；这是操作示例，不是要求你选择这部电影。

1. 在文件资源管理器中打开“评审案例”文件夹。此时能看到名为“新电影模板”的文件夹。
2. 单击“新电影模板”文件夹，按Ctrl+C，再按Ctrl+V。原文件夹旁边会出现它的副本。
3. 选中这个副本，按F2，将名字改成“爱乐之城”。现在“评审案例”里应同时有“新电影模板”和“爱乐之城”两个文件夹。
4. 打开“爱乐之城”，新建一个叫“展示材料”的文件夹，把自己的PPT、讲稿和媒体放进去。它们的位置就会是“评审案例 → 爱乐之城 → 展示材料”。
5. 告诉评审助手：“请评审《爱乐之城》，材料放在‘评审案例/爱乐之城/展示材料’。请你整理本案例的配置、收集影片资料，再按照教师画像评审。”其余JSON文件交给评审助手填写。

请保留原来的“新电影模板”，以后另一部电影仍可用它建立新案例。没有必要先把评论找齐；可以让评审助手按[资料收集指南](资料收集指南.md)查找。

## 供评审助手填写

- `案例配置.json`：片名、版本、展示文件、计时口径、报告位置。
- `逐页材料.json`：主讲/参考/备用页，以及每页对应的图片和媒体；由实际PPT与讲稿提取。
- `资料来源.json`：这部电影实际查到的评论、研究、访谈和事实来源，记录原网址与获取范围。

路径从整个项目最外层算起。例如最外层同时能看到“王伟华教师评审画像”和“评审案例”，那么上面的PPT可写成“评审案例/爱乐之城/展示材料/课堂展示.pptx”。不要沿用其它人的用户名、盘符或影片材料。
