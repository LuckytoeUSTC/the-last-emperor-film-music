## 用智能体评审自己的展示

“教师评审画像”是一套供智能体读取的评审说明与课程知识索引：把评分标准、课堂概念、证据边界和逐页听讲方法组织起来，帮助智能体检查PPT、讲稿与媒体，提出追问和修改建议。它适用于不同电影，但需要补充该片的专业评论与制作资料；它不代表老师本人，不能预测成绩，也不能把未实际听看的媒体当作已经核验。

点击本页上方 **Code → Download ZIP**，完整解压并保留目录结构，再按[画像使用说明](王伟华教师评审画像/README.md)启动独立评审。不要只下载画像文件夹：原讲义、文字稿和评分依据放在外部知识库中。
