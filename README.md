## 教师评审画像

这是一套可移植的评审配置，让你的智能体依据本课程知识和评分要求，模拟老师听一场展示，帮助你在排练前修改内容。

理解它需要三个概念：**角色指令、课程知识库、影片案例**。

**角色指令**规定评审怎样进行：先按放映顺序接收PPT、口播和媒体，记录当时的理解与疑问，再查参考资料，形成逐页意见。

评审的依据来自**课程知识库**。其中保存原讲义、评分要求及知识索引，把“这个判断涉及什么概念”与“去原文哪里核对”联系起来。

**影片案例**连接待审的PPT、讲稿与媒体，以及该电影的独立乐评、影评、研究和制作资料。智能体先阅读影片与评论，形成知识准备，再按现场顺序听展示，给出逐页追问和修改建议。更换电影时替换案例，课程知识库与评审方法继续使用。

本项目已连接[《末代皇帝》示例案例](评审案例/末代皇帝/README.md)与[影片专属资料](影片资料/末代皇帝/README.md)，可以查看这些资料如何进入评审。

想先了解AI教师画像会给出怎样的反馈，可以阅读[《末代皇帝》v10评审示例](评审案例/末代皇帝/评审输出/《末代皇帝》v10展示评审.md)。

**开始使用：**点击仓库上方 **Code → Download ZIP**，完整解压；让智能体以该目录为工作目录，按[画像使用说明](王伟华教师评审画像/README.md)开启独立评审。完整项目同时包含画像与它所读取的知识库。
